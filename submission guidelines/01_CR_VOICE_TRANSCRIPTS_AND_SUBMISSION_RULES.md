## 2. Synthesis of Official Submission Requirements

1. **Slide Deck Depth**:
   - Must be between 20 and 25 slides. Our deck contains exactly **22 slides**.
   - Must cover all 9 laboratory experiments (Requirements, Agile, Use Case, Activity, Class, Sequence, Collaboration, DFDs, Testing, Database, UI).

2. **Visual Standards**:
   - Zero emojis or cartoon graphics.
   - Clean, professional dark aviation executive aesthetic.
   - Natural human punctuation (no em dashes or en dashes).
   - High-contrast, legible diagram embeds.

3. **Database Expectations**:
   - Complete 41-table normalized 3NF relational schema in PostgreSQL 18.
   - Automated bootstrap via 20 versioned Flyway migrations with 158,660+ seed records.
   - Separate OLAP Star Schema & Information Package for Data Warehouse reporting.

4. **Live Application Integrity**:
   - Full-stack live connection: React 19 on `http://localhost:3000`, Spring Boot 3 on `http://localhost:8080`, PostgreSQL on port 5432.
   - Zero static mock data across all 16 web consoles.

5. **Video Demo Duration**:
   - Exactly 5:30 total duration.
   - 4 equal speaking slots: 1 minute 20 seconds per member.
